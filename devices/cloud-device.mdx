## Quash Cloud Devices

Quash lets you run tests on Android and iOS devices hosted in the Quash cloud. This is useful if you don’t want to set up local devices, emulators, or simulators.

To connect a Quash cloud device:

1. Open the Quash app.
2. Click on the **Profile** button in the top-right corner.
3. Select **Devices** from the left navigation panel.
4. Under **Quash Cloud Device available**, click **Connect**.

Once connected, a Quash cloud device will be assigned to you and will appear under **Connected Devices**.

Your subscription sets your cloud device allocation and parallel capacity. If the device remains inactive for **5 minutes**, it will be **automatically disconnected**.

If all cloud devices are currently in use, you may be placed in a queue. When a device becomes available, you will receive a notification allowing you to connect.

See [How Quash Pricing Works](/administration/how-quash-pricing-works) for how device allocation is scoped.

> Quash cloud Android devices come with the Mahoraga Android App pre-installed, so no additional setup is required. You can immediately start interacting with the device.

If you want to manually interact with the device, click the computer icon next to the connected cloud device to enable screen mirroring. This allows you to view and control the device directly from Quash.

Once connected, the Quash cloud device will appear as an option in the prompt box when you click on ‘Devices’, and you can start running tasks on it.

You can connect multiple cloud devices and run tests in parallel, up to the parallel capacity in your subscription. Included devices and parallel capacity are set out in your quote.
