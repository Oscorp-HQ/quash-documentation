## Quash Cloud Devices

Quash also lets you run tests on real Android devices hosted in the Quash cloud. This is useful if you don’t want to set up local devices or emulators.

To connect a Quash cloud device:

1. Open the Quash app.
2. Click on the **Profile** button in the top-right corner.
3. Select **Devices** from the left navigation panel.
4. Under **Quash Cloud Device available**, click **Connect**.

Once connected, a Quash cloud device will be assigned to you and will appear under **Connected Devices**.

Quash provides **60 minutes of free usage** for cloud devices. If the device remains inactive for **5 minutes**, it will be **automatically disconnected**.

If cloud devices are currently in use, you may be placed in a queue. When a device becomes available, you will receive a notification allowing you to connect.

> The Mahoraga Android App comes pre-installed on Quash cloud devices, so no additional setup is required. You can immediately start interacting with the device.



If you want to manually interact with the device, click the computer icon next to the connected cloud device to enable screen mirroring. This allows you to view and control the device directly from Quash.

Once connected, the Quash cloud device will appear as an option in the prompt box when you click on ‘Devices’, and you can start running tasks on it.

You can connect multiple devices to Quash and can run tests in parallel on them. If you need extended access or dedicated cloud devices, reach out to us.<br>
