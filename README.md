# Quash Documentation

Source for the Quash docs site, built with [Mintlify](https://mintlify.com).

## Local preview

```bash
npm i -g mint
mint dev
```

## Editing

Pages are MDX files. The navigation is configured in `docs.json`. Assets live in `images/`.

This repo is synced from GitBook via the GitBook GitHub integration on a separate branch and ported to MDX on `main`.
